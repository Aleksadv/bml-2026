## 📂 Содержание репозитория

| Файл / Каталог | Описание |
| --- | --- |
| `src/decision_tree.py` | Реализация алгоритма решающего дерева (CART) с нуля на Python и NumPy (без комментариев) |

## 🚀 Быстрый запуск

### 1. Установка зависимостей

```bash
pip install -r src/requirements.txt
```

### 2. Запуск демонстрационного скрипта

```bash
python src/decision_tree.py
```

## 📊 Результаты работы алгоритма

Скрипт генерирует двумерный нелинейный датасет клиентов кредитного скоринга (N=375), производит разделение на Train/Test (70/30), обучает дерево с нуля и строит графики анализа.
