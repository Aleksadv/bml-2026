# Влияние случайных шумовых признаков на качество модели

**Сагун Александр, № 40. Основы машинного обучения.**

## Задача

Исследовать изменение качества классификации при добавлении случайных признаков, независимых от целевого класса. Сравнить чувствительность разных моделей и проверить, помогает ли отбор признаков.

## Данные и решение

Используются три набора из scikit-learn:

| Набор | Объекты | Исходные признаки |
|---|---:|---:|
| `make_classification` | 1000 | 10: 8 информативных и 2 избыточных |
| `make_moons` | 1000 | 2 |
| Breast Cancer Wisconsin, `load_breast_cancer` | 569 | 30 |

К исходным данным добавляются 0, 10, 25, 50, 100 и 200 независимых признаков из нормального распределения N(0, 1). Исходные значения и метки классов сохраняются. Данные доступны в библиотеке или генерируются программно; скачивать их отдельно не требуется.

Сравниваются LogisticRegression, KNN, DecisionTree, RandomForest и MLP. Для каждой задачи выполняются пять стратифицированных разбиений 70/30 с фиксированными seeds. В каждом повторении все модели и уровни шума используют одинаковые обучающие и тестовые объекты. Основные настройки моделей фиксированы и приведены в notebook.

Масштабирование выполняется внутри `Pipeline` только по обучающей выборке. Основная метрика — balanced accuracy; также вычисляются accuracy, macro F1, log loss и accuracy на обучении. В notebook представлены средние, стандартные отклонения и парные изменения качества. Стандартное отклонение по пересекающимся разбиениям не интерпретируется как доверительный интервал.

Дополнительно проведены:

- отрицательный контроль: обучение только на 200 шумовых признаках и сравнение с DummyClassifier;
- анализ влияния случайных координат на расстояния между объектами;
- отбор признаков перед KNN через `SelectPercentile(f_classif)`: доля выбирается во внутренней 3-fold кросс-валидации, без использования внешней тестовой выборки.

## Результаты

Средняя balanced accuracy на наборе «две луны»:

| Модель | Без добавленного шума | +200 шумовых признаков |
|---|---:|---:|
| LogisticRegression | 86,2% | 79,7% |
| KNN | 93,8% | 67,6% |
| DecisionTree | 90,8% | 84,9% |
| RandomForest | 93,1% | 88,6% |
| MLP | 87,9% | 70,2% |

При добавлении 200 шумовых признаков среднее качество снизилось у всех моделей на всех трёх наборах. KNN оказался наиболее чувствительным. Лес потерял меньше качества, чем KNN и MLP, на каждом наборе; при этом на синтетической классификации одиночное дерево потеряло меньше, чем лес.

Отбор признаков повысил качество KNN на «двух лунах» с **67,6% до 85,3%**, но не восстановил исходные 93,8%. В отрицательном контроле средние оценки находились около 50%. Полные таблицы, семь графиков, объяснение результатов и ограничения исследования сохранены в notebook.

**Вывод:** дополнительные столбцы не обязательно содержат полезную информацию. Независимые признаки могут искажать расстояния и способствовать переобучению; их отбор следует проверять внутри корректной процедуры валидации. Выводы относятся к использованным наборам, настройкам и независимому гауссову шуму.

## Запуск

Проверено на **Python 3.12**. Открыть терминал в папке работы и установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Открыть `src/solution.ipynb` в VS Code с расширениями Python и Jupyter. Выбрать Python-окружение, в которое установлены зависимости, и нажать **Run All / Выполнить всё**.

Все 780 обучений, таблицы и графики пересчитываются автоматически. Выполнение занимает несколько минут в зависимости от компьютера. Промежуточные CSV и изображения создаются во временной папке; итоговые таблицы и изображения отображаются в notebook. Для просмотра готового отчёта повторный запуск не нужен: выводы ячеек уже сохранены.
