Индивидуальные задания

В этом каталоге размещаются индивидуальные задания студентов по предмету «Основы машинного обучения».

Структура работы

Каждый студент создаёт отдельный каталог со своим номером в соответствии с файлом Teams.xlsx:

NN-Фамилия-Имя/

В каталоге должны находиться:

README.md — тема задания, краткое описание решения, используемые данные и инструкция по запуску;

src/ — исходный код или Jupyter Notebook;

requirements.txt — необходимые библиотеки, если используются дополнительные зависимости.
