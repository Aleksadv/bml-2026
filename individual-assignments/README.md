# Индивидуальные задания

В этом каталоге размещаются индивидуальные задания студентов по предмету **«Основы машинного обучения»**.

## Именование каталогов

Каждый студент создаёт отдельный каталог:

```text
NN-Фамилия-Имя/
```

Где `NN` — двухзначный номер студента из файла [Teams.xlsx].


## Структура работы

```text
├── README.md
├── requirements.txt
└── src/
    ├── solution.ipynb
    └── дополнительные файлы
```

В каталоге должны находиться:

- `README.md` — тема задания, краткое описание решения, используемые данные, полученные результаты и инструкция по запуску;
- `src/` — исходный код на Python или Jupyter Notebook;
- `requirements.txt` — список дополнительных библиотек, необходимых для запуска работы.

Если дополнительные библиотеки не требуются, файл `requirements.txt` можно не добавлять.
